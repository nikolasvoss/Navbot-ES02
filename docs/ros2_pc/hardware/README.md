# ros2_pc-Hardware

This directory documents the ros2_pc, its carrier board, power supply, connectors, and attached hardware.

The project has not yet recorded confirmed ros2_pc or carrier-board details here. Do not infer pin assignments, power limits, or peripheral connections from the roadmap. Add each fact with its board revision and evidence when the hardware is selected or inspected.

The [ros2_pc carrier-board pinout](ros2-pc-carrier-board.md) is a reference. It does not confirm that the project has selected or verified that carrier board.

The planned HMMD radar and Roborock LiDAR work is listed in the [ros2_pc software roadmap](../software/roadmap.md). Record their electrical and mechanical details here only after the exact modules are identified.
