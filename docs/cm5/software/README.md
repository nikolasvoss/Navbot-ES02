# CM5-Software

This directory documents software that runs on the Compute Module 5, including its operating system, ROS 2 packages, services, applications, and deployment steps.

The roadmap tracks future ROS 2 work and live acceptance status.

- [HMMD ROS 2 developer guide](hmmd-ros2.md) for the current build, startup, browser, topic, and recording workflows.

The HMMD ROS 2 workspace is under `src/cm5/ros2/`.
