# CM5-Hardware

This directory documents the Compute Module 5, its carrier board, power supply, connectors, and attached hardware.

The project has not yet recorded confirmed CM5 or carrier-board details here. Do not infer pin assignments, power limits, or peripheral connections from the roadmap. Add each fact with its board revision and evidence when the hardware is selected or inspected.

The [Raspberry Pi CM5 IO Board pinout](compute-module-5-io-board.md) is a manufacturer reference. It does not confirm that the project has selected or verified that carrier board.

The planned HMMD radar and Roborock LiDAR work is listed in the [CM5 software roadmap](../software/roadmap.md). Record their electrical and mechanical details here only after the exact modules are identified.
