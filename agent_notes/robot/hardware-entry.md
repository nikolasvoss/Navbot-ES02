# Robot hardware entry for agents

Read the [canonical system overview](../../docs/robot/hardware/system-overview.md) first. Open only the needed section of the [electronics reference](../../docs/robot/hardware/electronics/reference.md), then search the [netlist](../../docs/robot/hardware/electronics/netlist.md) for exact designators or nets.

The PCB netlist describes intended connections. Firmware describes configured behavior. The BOM lists proposed parts. Notes under `agent_notes/robot/hardware-findings/` record observations on the assembled robot. Check the physical board when orientation, assembly, or actual wiring remains uncertain.

Before a flash, recheck the board and serial device. See the [USB and serial reminder](usb-serial.md) and the complete [USB and flashing guide](../../docs/robot/software/development/usb-serial-flashing.md).
