Hardware and setup notes

UART0 uses J8 pin 8 (GPIO14 TX) and pin 10 (GPIO15 RX). LiDAR TX is received on /dev/ttyAMA0; leave LiDAR RX disconnected.

Use J8 pin 4 for 5 V and pin 6 for ground only after supply and current checks. No motor GPIO or PWM output is enabled.

M− is reported at 5 V idle and needs an external transistor sink. TX is reported at 3 V peak; the earlier DMM reading was 1.8 V. The 15 October 2026 capture and live UART scans confirm Camsense at 115200 baud, 8N1. Voltage levels were not independently measured.

0° is the robot's front and angles grow clockwise; the front was set from one user reading and is not otherwise calibrated. See docs/ros2_pc/hardware/lds08rr-lidar.md for setup and evidence.

Software uses the LDS08RR Camsense driver from lds2d[viz]==0.7.0.

On the robot, install ROS 2 Jazzy and create the documented Python environment:

python3 -m venv --system-site-packages "$HOME/.venvs/navbot-lidar"
source "$HOME/.venvs/navbot-lidar/bin/activate"
python -m pip install 'lds2d[viz]==0.7.0'

Run these commands from the project checkout. Use --demo to check the page without hardware:

python scripts/start_lidar.py --demo --host 0.0.0.0

Replace --demo with --device /dev/ttyAMA0 for live scans. Source /opt/ros/jazzy/setup.bash to enable ROS output.

Confirm that no console or other process owns /dev/ttyAMA0, and verify supply, ground, connector mapping, and signal voltage before wiring. UART2 and its overlay are reserved for the HMMD radar.
